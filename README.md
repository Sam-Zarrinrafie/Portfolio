# Sam Zarrinrafie — Engineering Portfolio

Static personal portfolio hosted with GitHub Pages.

## Structure

- `index.html`: profile, selected projects, capabilities, and contact information.
- `farmtron.html`: detailed Farmtron engineering case study.
- `styles.css` and `site.js`: responsive layout, image lightbox, and model controls.
- `assets/images`: optimized project photography and engineering renders.
- `assets/models`: browser-ready interactive 3D model.
- `assets/videos`: project video with its audio track removed.
- `assets/Sam-Zarrinrafie-Resume.pdf`: current resume.

No build step, backend, API keys, or package installation required. Preview with `python -m http.server 8000` and open http://localhost:8000.

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` publish automatically.

The Farmtron case study describes product-development work at STEM MINDS CORP. This repository contains portfolio material only, not product source code or internal control software.

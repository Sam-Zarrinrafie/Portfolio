# Sam Zarrinrafie — Engineering Portfolio

Static personal portfolio hosted with GitHub Pages.

## Edit

- `index.html`: project descriptions, experience, and contact information.
- `styles.css`: responsive layout, colors, and typography.
- `farmtron.png`: Farmtron assembly illustration.
- `Sam-Zarrinrafie-Resume.pdf`: approved resume.

No build step, backend, API keys, or package installation required. Preview with `python -m http.server 8000` and open http://localhost:8000.

GitHub Pages serves the root of the `main` branch. Changes pushed to `main` publish automatically.

The Farmtron illustration describes product-development work at STEM MINDS CORP. This repository contains portfolio material only, not product source code or the full assembly guide.
